# Производительность

Сколько стоит Vectra: замеры стендом из `Perf~/` (как запустить его самому, написано в его README).

## Как мерили

Windows 11, Ryzen 7 4800H, RTX 3060 Laptop, D3D12, 1280x720, vSync выключен. Unity 6000.4.8f1, URP 17.4, цветовое пространство Linear. Релизные плееры IL2CPP, медиана по 5 запускам; аллокации и счётчики отрисовки из development-плееров. Для сравнения: обычный uGUI `Image` (sliced-спрайты, без аналитического сглаживания, пунктира и градиентов), `SpriteRenderer` в мировом пространстве, `VisualElement` UI Toolkit со скруглением и `com.unity.vectorgraphics` для SVG. Набор фигур: скруглённый прямоугольник, эллипс, звезда, скруглённый прямоугольник с пунктирной обводкой и с градиентом, по 20 px.

## Известные издержки

- Пунктирная обводка рисуется по трапеции на каждый отрезок (128 треугольников у пунктирного прямоугольника 20 px). 200 таких фигур дают большую часть времени видеокарты в кадре из 1000 фигур (1,19 мс против 0,18 мс у uGUI); без них Vectra на видеокарте наравне с uGUI.
- Выключение 1000 фигур на Canvas стоит примерно на 1 мс больше, чем в 0.7.5 (5,4 против 4,6 мс; uGUI `Image`: 5,1 мс): фигуры Canvas делят один рабочий меш, как и графика самого uGUI. Именно общий меш экономит 16 МБ на 1000 фигур.
- Создание фигур в мире и SVG-иконок всё ещё в разы дольше создания спрайтов: основное время уходит на `AddComponent` движка и первую сборку каждого меша.
